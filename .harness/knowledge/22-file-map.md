# 功能与文件映射

## 应用入口与配置

- FastAPI 应用入口：`app/main.py`，提供 `create_app`，组装 Infrastructure 具体实现并注册 HTTP/Dashboard 路由；`create_app()` 调用 `_configure_logging()` 配置 HTTP 进程的 root logger（level=INFO + StreamHandler 到 stderr，修复 uvicorn 0.30+ 默认 LOGGING_CONFIG 不再配置 root logger 导致应用 `logger.info()` 静默；basicConfig 幂等，root logger 已有 handler 时不覆盖）；模块 import 不配置日志，避免复用 `build_application_services()` 的 CLI/TUI 入口泄漏 INFO 日志；当 `settings.context_compression_enabled=True` 时构造 `ContextCompressor`（注入 LLMProvider/model callable/context_length/threshold/protect_first_n/protect_last_n/summary_target_ratio/cooldown_seconds）并注入 `AgentGraphRunner.context_engine`；装配 SkillUsageStore/SkillPendingStore/SkillBackupStore/SkillPolicy/SkillEvolutionService，SkillService 注入 usage/pending/backup/policy 依赖，SkillManageToolExecutor 注入 routes，AgentGraphRunner 注入 evolution_service，ApplicationServices 暴露新字段；host_terminal 三态（disabled/配置失败/成功）均构造 `HostTerminalDashboardService`（成功时保留 policy_loader 引用，失败时传 None + 稳定 unavailable_reason）并注入 create_dashboard_router 无条件注册 host 路由；Task 子系统 `settings.task_enabled` gating（false 跳过整个子系统、task_service/task_run_service/task_runner 保持 None、不注册用户侧工具、lifespan 不启动 dispatcher；true 时 `SQLiteTaskRegistry` 初始化异常 fail-fast 传播不静默降级，从 fail-soft 改），启用时装配五个用户侧工具（create_task/list_tasks/approve_task/reject_task/revise_task）到唯一 source key `user_task` + 启动断言五工具名不与既有 static/dynamic 定义或 route 冲突；`_task_lifecycle_writer(session_id, content, card=None)` 闭包把第三参数透传给 `session_service.append_task_lifecycle_message`，`SessionNotFoundError` 静默跳过不复活，其它异常由调用方 broad except 记 warning
- 配置模型：`app/config.py`，定义 `Settings`，从 `.env` 和环境变量读取 `N_AGENT_` 配置；含 7 个上下文压缩字段（`context_compression_enabled`/`context_length`/`context_compression_threshold`/`context_compression_target_ratio`/`context_compression_protect_first_n`/`context_compression_protect_last_n`/`context_compression_cooldown_seconds`）及跨字段校验 `target_ratio < threshold`；含 Skill 自进化字段（`skills_creation_nudge_interval`/`skills_background_review_*`/`skills_write_approval`/`skills_guard_agent_created`/`skills_backup_*`/`skills_archive_not_delete`）
- Python 依赖：`pyproject.toml`，定义运行依赖、dev 依赖和 pytest 配置
- 环境变量模板：`.env.example`，不包含真实密钥；当前仓库可能不存在该文件，不能改写包含本地密钥的 `.env` 作为替代

## Application Layer

- Host Terminal 能力与工具执行器：`app/application/host_terminal_capability.py`、`app/application/host_terminal_tool_executor.py`，负责 Policy 刷新、容器/宿主路径映射、双重校验前置与 `host_terminal` ToolResult 映射；定义 `ImagePersister` Protocol，photo 能力成功后调用其 `persist(signed_url)` 把临时 OSS 签名 URL 替换为永久 serve URL（失败回退原 URL，详见 Infrastructure `LocalImageStore`）
